# Аким на 5 часов

Командный хакатон-проект Datalicious: AI-симулятор распределения городского
бюджета и оценки Astana Quality of Life Score на синтетических данных.

**Состояние: 3D-город и выбор решений.** На карте можно выбрать один из пяти
районов, изучить его потребности и добавить меры в план. Есть каталог 14 мер,
контроль бюджета и ограничений, синергии и ручное сохранение в браузере.
После запуска пяти решений включается 10-секундная анимация работ с пропуском.
За городом стоит процедурный робот: отслеживает курсор головой и рукой через
raycasting и IK. Панель района показывает все 10 показателей и общую оценку.
Оформление использует тёмные поверхности и мятные акценты Astana Innovations.
Сохранены крупные контуры районов OSM, поверх них — 160 условных 3D-домов
с окнами и разными крышами. Детальная подложка центра убрана; это игровой
макет. Сарайшык виден без выдуманных показателей: датасет содержит пять районов.
Демо работ показывает автобусы, бригады и общественные мероприятия;
кнопка ◎ приближает площадку. Реальное выполнение не имитируется.
[Источники и ограничения карты](docs/GEODATA.md).
До интеграции домена интерфейс использует отдельный временный адаптер выбора
и исходные контрольные оценки из датасета. Формулы Score в интерфейсе нет.
Расчёт последствий, графики результата и AI-анализ предстоит реализовать.
`POST /api/analyze` сейчас возвращает HTTP 501 `NOT_IMPLEMENTED`.

## Запуск

Node.js ≥22.12 (рекомендуется Node.js 24) и npm.

```sh
npm ci
npm run dev
```

Открыть http://localhost:3000. Секреты для каркаса не нужны.
В Windows PowerShell с запретом `.ps1` используйте `npm.cmd` и `npx.cmd`.

Для будущей интеграции скопируйте `.env.example` в `.env.local`, заполните
`OPENAI_API_KEY` и доступную вашему проекту `OPENAI_MODEL`. Не коммитьте ключ.
Ключ используется только на сервере, реальных AI-запросов в каркасе нет.

## Проверки

```sh
npm test
npm run lint
npm run typecheck
npm run build
npx playwright install chromium
npm run test:smoke
```

`typecheck` сначала генерирует типы Next.js и работает на чистом клоне.
Smoke запускает production-сервер на 127.0.0.1:3100; build обязателен заранее.
Smoke проверяет реальный 3D-рендер и робота, выбор контрольного набора
на 95 единиц, 10-секундную анимацию, восстановление после перезагрузки и
отсутствие горизонтальной прокрутки на телефоне и ноутбуке, без API-ключа.
Проверяются touch/reduced motion и запасной интерфейс при потере WebGL.
Production-запуск после сборки: `npm start`.
