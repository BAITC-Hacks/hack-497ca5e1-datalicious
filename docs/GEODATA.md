## Игровой макет

По выбору пользователя основной вид — полные крупные контуры районов.
Детальная прямоугольная подложка центра и реальные контуры отдельных зданий
убраны. Вместо них в пределах районов стоят 160 условных объёмных домов:
разная этажность, скатные/плоские крыши, окна и входы. Они не изображают
конкретные адреса. Генерация детерминирована, учитывает границы, свободное
место около подписей и коридоры демонстрационных маршрутов.
Дома объединены в три геометрии для экономии draw calls.

Контуры используют локальную проекцию вокруг 71.43° E, 51.145° N:
1 единица сцены = 1 км; восток +X, север −Z. Масштаб домов художественный.
Робот процедурный, стоит в той же сцене за городом. Готовой GLB-модели нет.

Маршруты и площадки взяты из центральной выгрузки OSM
71.35–71.51° E, 51.085–51.205° N. Кнопка ◎ приближает площадку текущего
этапа, ↺ возвращает общий вид. Неиспользуемая детальная геометрия не входит
в клиентскую загрузку; сохранены только контуры и необходимые для демо данные.

## Демо действий

Десять секунд — длительность демонстрации, **не процент реального выполнения**.
Индикатор показывает пять этапов воспроизведения. Результат сервера не
имитируется: API и расчёт последствий ещё не подключены.

Автобусные демо-маршруты собраны из связанных узлов OSM, учитывают oneway,
остаются внутри района, не проходят через воду без bridge и имеют отступ
от известных зданий. Это не реальные маршруты перевозчика. Остановки взяты
из OSM и спроецированы на ближайший выбранный участок дороги. Движение
линейное по сегментам, со сглаживанием поворота корпуса и паузами; в конце
автобус останавливается. Скорость и размер маркеров увеличены для видимости.

M1/M3 показывают дорожную площадку, M2 — регулирование движения. Социальные
меры показывают условное открытие/общественную активность на существующих
пешеходных дорожках парков: учебную, медицинскую или спортивную. Это не
предложенные участки строительства школ/поликлиник. Остальные категории
получают озеленение, оборудование, освещение или бригады ЖКХ.

Не более 7 автобусов, 12 прохожих и 24 частиц при валидных пяти решениях.
Фейерверк краткий, только в конце социального этапа. Reduced motion
останавливает движение и отключает фейерверк, сохраняя появление объектов.
Повторный запуск пересоздаёт слой с освобождением предыдущих ресурсов.

## Обновление снимка

`scripts/fetch-astana.py` получает районы через OSM API `relation/.../full.json`
и 16 ограниченных фрагментов карты `map.json`. Raw-кеш находится в
`.cache/geodata` и не коммитится. Запросы выполняются максимум по два.
Первоначальный Overpass оказался нестабилен; данные получены через OSM API.

Для сборки: Python 3.12+, Shapely 2.x. Выполнить fetch-astana.py, затем
build_astana.py. Скрипт проверяет наличие замкнутых районов, маршрутов и
общественных площадок. Файл `src/components/city/geodata/astana.json` содержит
геометрию, OSM IDs, метаданные, выбранные маршруты и места активности.
