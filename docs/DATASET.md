## Каталог мероприятий

Горизонт H = 8 кварталов (2 условных года). Лаг L — через сколько кварталов мера
начинает работать. Реализованная доля эффекта: `(8 − L) / 8`.
«Район» действует только в выбранном районе; «Город» — во всех пяти.

## Синергии и несовместимости

Бонус срабатывает при выборе обеих мер, в районе первой меры пары из таблицы,
без масштабирования лагом. Порядок решений пользователя не важен.

| Пара | Бонус |
| --- | --- |
| M1 + M2 | T1 +2 в районе M1 |
| M10 + M12 | B1 +2 в районе M10 |
| M5 + M6 | E2 +2 в районе M5 |

| Пара | Ограничение |
| --- | --- |
| M1 + M3 | Запрещены вместе в любых районах: либо BRT, либо ЛРТ |
| M4 + M7 | Запрещены в одном районе: конфликт за участок |
| M5 + M13 | Запрещены в одном районе: дублирование программы |

## Формула Score

1. `I′[d,k] = clip(I[d,k] + Σ(effect[m,k] × (8 − L[m]) / 8) + synergies[d,k], 0, 100)`.
2. Оценка района: `D[d] = Σ(w[k] × I′[d,k])`.
3. Городской балл: `D_avg = Σ(pop[d] × D[d])`.
4. `Score = 0.7 × D_avg + 0.3 × min(D[d]) − 1.0 × N_crit`.

`N_crit` — число пар «район × показатель» со значением **строго меньше 40**
после всех эффектов. Ровно 40 не штрафуется. Clip выполняется после суммирования
эффектов и синергий, чтобы порядок решений не влиял на результат.
Округление — только при отображении. Отдельного clip итогового Score нет.

70% веса отвечает за общий результат, 30% — за самый слабый район.
Критический штраф не позволяет игнорировать провалы.

База из исходника: **52.56** (`0.7 × 56.86 + 0.3 × 49.18 − 2`).
Точные значения из указанных весов: `D_avg = 56.8624`, `Score = 52.55768`.
Два критических показателя — S1 и S2 в Нуре.

## Правила

- Бюджет 100. Остаток не сгорает и не даёт бонуса.
- Ровно 5 решений; каждое мероприятие максимум один раз.
- Район обязателен для районной меры и не указывается для городской.
- До 2 мер одного направления; следовательно, минимум 3 направления.
- Все несовместимости запрещены.
- Невалидный набор не получает Score: валидатор возвращает причину.
- Порядок решений значения не имеет.

Пример выше валиден: 95 ≤ 100, пять мер, без повторов, по направлениям 2/1/1/1,
без конфликтов. Дешёвый набор M9 + M11 + M10 + M12 + M4 стоит 61; для районных
мер нужно указать районы. Требования по одной мере каждого направления нет.
