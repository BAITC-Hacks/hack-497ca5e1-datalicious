# AI-анализ — разработчик 3

`openai.ts` содержит только ленивую серверную фабрику SDK и проверку конфигурации Zod.
`AnalysisService` ещё не реализован. Каждый исполняемый модуль здесь начинается
с `import "server-only"`. Ключ и модель читаются только на сервере.

Добавить `analyze.ts`, Zod-схему структурированного ответа, промпт и тесты с mock SDK.
LLM получает `SimulationResult`, объясняет его и не рассчитывает числа.
API повторно рассчитывает результат по присланным решениям и серверному датасету;
не доверяет присланному клиентом Score. Ошибки провайдера не должны раскрывать ключ,
промпт или сырой ответ; сетевые запросы ограничить тайм-аутом.

Каркас не делает платных запросов и работает без `.env.local`.
Фабрика соответствует [официальной документации OpenAI SDK](https://developers.openai.com/api/docs/quickstart).
