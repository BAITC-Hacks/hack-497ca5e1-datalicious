# Доменная модель — разработчик 1

Общие контракты находятся в `types.ts`. Реализация `SimulationEngine` пока отсутствует.
Добавить `validation.ts` (Zod + бизнес-правила), `score.ts` (чистый расчёт),
`index.ts` (публичные экспорты) и тесты. Сигнатуры реализации следуют интерфейсу
`SimulationEngine`: `validate(input: unknown)`, `evaluate(input: unknown)`, `baseline()`.

Домен может импортировать `src/data` и Zod. Он не зависит от React, Next.js,
окружения сервера или OpenAI. `evaluate` сначала валидирует; при ошибке не возвращает Score.
`baseline()` вычисляет исходные показатели отдельно: пустой пользовательский набор невалиден.
Не мутировать датасет, не округлять промежуточные значения. Подробности в `docs/DATASET.md`.
