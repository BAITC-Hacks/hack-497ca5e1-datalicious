# Доменная модель

`types.ts` содержит общие сериализуемые контракты. Публичный API экспортируется
из `index.ts`: `simulationEngine`, `createSimulationEngine`, `validateScenario`,
`evaluateScenario` и `getBaselineScore`.

Движок проверяет форму входных данных и правила организаторов: ровно пять
разных мероприятий, бюджет, лимиты направлений, районы и несовместимости.
Валидный сценарий нормализуется по ID мер, поэтому порядок решений не влияет
на расчёт. Невалидный сценарий возвращает коды ошибок без Score.

`evaluate` считает лаг-масштабированные эффекты, синергии и ограничивает
показатели диапазоном 0–100, после чего возвращает Score, критические показатели,
дельты районов и вклады мер. `baseline()` вычисляет исходные показатели отдельно.

Модуль импортирует только типы, данные и Zod. Он не зависит от React, Next.js,
серверного окружения или OpenAI. Расчёт не мутирует датасет и не округляет
промежуточные значения. Правила и исходные числа описаны в `docs/DATASET.md`.
